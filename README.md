# 🎙️ Hegemonia Recorder

سكربت بيسجّل طلبات لعبة [Hegemonia](https://hegemonia.gg) ويبعتها لقاعدة بيانات بوت Hegemonia عشان نطوّر البوت منها.
A userscript that records Hegemonia's API requests into the Hegemonia Bot database so the bot can be built from them.

## التركيب / Install

**[⬇️ اضغط هنا للتركيب / Click to install](https://raw.githubusercontent.com/alielzahed49-art/hegemoniarecorder/main/hegemonia-recorder.user.js)** — محتاج Tampermonkey (كمبيوتر) أو متصفح Via (أندرويد).

- Tampermonkey: افتح الرابط فوق ← Install.
- Via: الإعدادات ← Scripts ← + ← استيراد من رابط ← الصق الرابط ده:
  `https://raw.githubusercontent.com/alielzahed49-art/hegemoniarecorder/main/hegemonia-recorder.user.js`

بعدها افتح hegemonia.gg والعب عادي — علامة **REC** هتظهر في جنب الشاشة.

## الأمان / Safety

- التوكنات وكلمات السر بتتشال من أي حاجة قبل ما تتبعت. التوكن بيظهر في لوحة السكربت بس عشان تنسخه.
- المفتاح اللي جوه السكربت بيقدر **يضيف** طلبات بس — مبيقدرش يقرا أو يمسح أي حاجة، ومبيقبلش غير روابط hegemonia.gg.
